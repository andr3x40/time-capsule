Version 1

For the beginning, I'm focusing on the most important aspects of this website.

Making a static website using every single feature HTML, CSS and JavaScript have to offer can be complex. But if this is the price to pay for having something I can easily call "personal", then I'm up for it.

Doesn't really help me when I only learned how to do dynamic websites, with databases and stuff, but I can come up with something. In fact, I already did.
