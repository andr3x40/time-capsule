Devlog 5 - GitHub Integration

Retrieving date...

If you're seeing this post, it means this website finally has a repository and automatic deployment through GitHub!

It was getting hard to develop only using Neocities, even if it was working pretty well. The problem is that I like using git and I like having stuff functional but not ready to be published.
Also, I reached a point where I have to refresh my browser's cache every five minutes when I'm doing changes. That's not a very big issue at the moment, but I don't want to waste widthband at any given time, even if I have plenty of it.

I'm pretty used to having an IDE to do these things and using Neocities's in-built editor is limiting. I can't edit multiple files without mixing them up, which is something that happens quite frequently.
Luckily, Neocities has an API that I can use to edit locally and then deploy the website when all the changes are ready. Because I like it this way.

If you're curious about how I did this, I followed this guide by DeadRodrick on Neocities along with the documentation for the GitHub action so I can set this up the way I like it.

...guess who messed up his first deploys?

Devlog 3 - Understanding Aero

Retrieving date...

It was coming from the start. This website will have an Aero theme.
It was there when I was using Windows 7. It was on my Wii, my 3DS and my Wii U. It was partially on my PS4 as well. And I absolutely LOVED it. I still like it to this day.

I decided to have a sort of Frutiger Aero style for this time capsule because... well... it's a time capsule. The style I've seen for most of my life (and I still see today, because of my 3DS) had to be here. I could've gone even more back in time and create a more XP-esque* style, but I like Aero more.

*after some research, I discovered that theme has a name and is called "luna". I didn't know that lol

It was a nightmare to set up and it will be a nightmare to set up. Now I know why everybody has moved to minimalism: it's 100 times easier to make, at the cost of... being a flat design.
I still like it, I'm a fan of flat designs if they play with shapes.

It will be easier when the @function CSS rule will be Baseline, but for now I have to do everything by hand, spamming copy-and-paste so much that my Control, C and V keys break.
I'll also have to look to a lot of references to faithfully recreate this kind of style. I don't want to miss anything. There have to be some other guides on Microsoft's website.

Also, speaking of Frutiger Aero: now we're on that weird imitation which is Liquid Glass, but it's incredibly heavy on graphics and... it's just weird. Telegram sort-of has it, and it's sooo roundy and weird with buttons. Everybody was so hyped (even I) but... it's not the same thing.

I'll add other themes when I know how to swap between them, but Liquid Glass is not on the list. Too resource-demanding.

Devlog 2 - Static & Dynamic

Retrieving date...

You have NO idea how much time it took for me to create a working list with search options and dialogue boxes. I was so used to Bootstrap or PrimeNG (I was using Angular back then) and... man, this is complicated.

Long story short: for Project R I had to create a list system to display all of my charts I made for Clone Hero. I had to create some way to not display too many information at once, but show everything needed with the click of a button, but more importantly...
I had to learn how to create something that would work dynamically. In a static website.

The reason is simple: I have soooo many charts (around 250) that I need to lay down in a single page. There's a lot of problems in doing it one by one:

  • I have a lot of info and data to show, so I have to display them in a way that's not overwhelming (I like minimalism)
  • That data may change in the future because I may release fixes to the charts
  • An entire page could weigh a whole MB
And because of this, I put every data inside a JSON file, made a JavaScript to read that file and created the list dynamically using a template. Then I placed a dialogue box for all info to show (took me two days to get the design right) and added filters and a search box.

And now, that thing works beautifully. All the data is messed up and there's only 60 charts, but I'll fill all the correct data afterwards.

I'm not adding pagination because there's a search box and the list is compact enough for me to not care much, but I'll add more filters (and sorting, obviously). But now I'm going to waste time on Binding of Isaac, sorry.
