Introduction

This Code of Conduct contains rules I've been following since the beginning of my charting adventure in 2020.
It's not my intention to harm others and I'm fully aware of the potential damage I may cause with this project.

My goal is to follow fair use guidelines and laws in the best way possible while nullifying the negative effects of this project with the positives.
Every single thing from Project R is made without intention of copyright infringement of any kind. All credits are given to the right people.

Charter's Code of Conduct

This is a hobby project based on sharing music through rhythm games. Therefore I'm not making money in any way from this.
Anything related to Project R, such as downloading, playing, sharing charts, setlists or packs, is free of charge and without financial gain of any kind.
I'm not open to paid commissions either. I'm happy to take requests, but always for free.

I'm not charting songs released in the last 14 months if those can still generate revenue.
It sounds stupid, but for me it feels wrong (and risky) to chart a song that was recently released. For example, if something came out in April 2026, I won't begin charting it until June 2027.
The artist is always credited in the best way possible, with links to the song given whenever possible.

Charts are always shared in a .sng binary container, which contains all the files needed for the chart with data masked using a simple XOR algorithm. Rhythm game emulators are able to read said files and it's not necessary to extract them.
note: older charts are still in a RAR archive, I'm working on changing that

Finally, I have no idea what the people will do with the downloaded charts. I'm not responsible for anything they may do.
This stuff is intended to be used only on rhythm games and nowhere else, and it will always be like this.

User's Code of Conduct

When downloading a chart, the user can:

  • play the chart in a supported rhythm game emulator of their choice, privately or on stream (remember to mute the VOD in this case)
  • share the chart with friends

Users are advised to:

  • keep the .sng container intact and not extracting it for any reason
  • not resell the charts (basically scamming people)
  • not lock charts' play under payment

In short: download the chart, load it into the game and leave it there.
